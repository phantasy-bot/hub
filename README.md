# Phantasy Hub

Public discovery and install registry for first-party Phantasy extensions.

## Public counts

- Plugins: 20
- Skills: 46
- Workflows: 3
- MCP Servers: 6

## Registry files

- `public/registry/extensions.json`: full public extension catalog
- `public/registry/plugins-published.json`: npm-published public plugins
- `public/registry/mcps.json`: first-party MCP preset bundles
- `internal/extensions-internal.json`: internal/private extension records for ops use
